### How to use it

1. Open a terminal and run `claude` to start a Claude Code session
2. You'll need to authenticate with your Anthropic API key on first run
3. Then ask Claude to create an agent team, for example:
   ```
   Create an agent team to review this codebase from different angles:
   one on architecture, one on security, one on test coverage.
   ```

### Display mode
By default it uses **in-process mode** (all teammates in one terminal). Use **Shift+Down** to cycle through teammates. 

> **Note:** Split-pane mode (`tmux`) has known limitations on Windows. The in-process mode works in any terminal and is the recommended option on Windows.

### Key things to know
- Agent teams use **significantly more tokens** than a single session
- Start with **3-5 teammates** for best results
- Teammates **don't share** conversation history — provide context in spawn prompts
- Ask the lead to **clean up the team** when done
